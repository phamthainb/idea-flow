# **App Name**: IdeaFlow

## Core Features:

- Idea Listing: Display ideas in a card layout with name, description, and status.
- Sort/Filter: Implement a sort/filter bar to organize ideas by priority criteria.
- New Idea Form: Create a form to input idea name, detailed description, tags, and custom criteria.
- Google Sheets Integration: Use Google Sheets API v4 to save and retrieve ideas.
- Idea Detail View: Display the complete details of an idea with inline editing.
- AI Scoring: Implement AI to score ideas automatically based on defined criteria, acting as a tool to provide automatic evaluations based on multiple criteria.
- Performance Chart: Display a performance chart comparing idea scores.

## Style Guidelines:

- Primary color: Soft green (#A2E499) for a fresh, innovative feel.
- Background color: Very light green (#F2FAF0) for a clean, uncluttered look.
- Accent color: Teal green (#73AFA5) for call-to-actions and highlights.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward feel.
- Body font: 'Inter' (sans-serif) for clear, readable text.
- Use minimal icons from Lucide-react or Heroicons for a consistent, clean aesthetic.
- Employ a responsive grid/flex layout to ensure adaptability across devices.
- Cards with rounded corners (2xl) and subtle shadows to lift content.
- Subtle transitions on card hover and button clicks to improve interactivity.
